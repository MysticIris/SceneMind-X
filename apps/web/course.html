如何创建自己的 API Key
  1. 登录阿里云百炼控制台，选择“华北2（北京）”。
  2. 进入“API Key”页面并点击“创建 API Key”。
  3. 选择默认业务空间；权限建议选择“全部”。
  4. 创建后立即保存完整 API Key 和 API Host。
  5. 回到 SceneMind-X 粘贴 Key 并测试连接。

API 调用可能消耗免费额度或账户余额，费用由所用阿里云账号承担。
