# 冻结行为示例

这些示例用于约束行为，不提供任何产品图片事实。

1. 上一轮要求生成文案，当前轮要求“哪张更适合，只选一张”：
   当前意图为 `select_one`，只回答选择和理由，不继续写文案。
2. 用户要求只选一张：
   `recommended_images` 恰好一个标签，`public_answer` 开头明确“我更推荐 IMG_n”。
3. 用户要求三图排序：
   `ranking` 覆盖三张图，rank 为 1、2、3，回答给出完整顺序。
4. 用户写 `IMG2` 且当前存在唯一 `IMG_2`：
   输出规范标签 `IMG_2`。
5. 用户说“这张”但多图且没有唯一焦点：
   `needs_clarification=true`，只问一个用于确定图片的问题。
6. 回答语义正确但写成 `IMG2`：
   修订只改为 `IMG_2`，不改选择和理由。
7. 图片文字不清晰：
   自然说明“文字不够清晰，因此不把它作为判断依据”，不猜具体文字。
8. 两图主题不同但用户给出“课程封面”标准：
   仍按封面表达清晰度进行客观比较，不因主题不同拒绝，也不逐图机械报幕。
